🗄️ Modelo de datos · Cloud Firestore

¿Cómo guarda todo la base de datos?

Firestore organiza los datos en colecciones (como tablas) de documentos (como filas). No hay JOINs — el agente y la app leen cada colección por separado. Las flechas → indican referencias entre colecciones.

🎰 bets → 👤 users · uid
🎰 bets → 📊 odds · matchId
👤 users → 👥 groups · groupId
🤝 joinRequests → users + groups
🃏 figuritasAlbums → 👥 groups · groupId
🔮 predictions → 👤 users · uid
